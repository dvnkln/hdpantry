# hdpantry

A self-hosted pantry tracker for reusable vacuum containers and bags with a QR code: scan a container, note what is inside, and see what should be eaten first.

Single user, one Docker container, all data in one SQLite file. hdpantry makes no connections to the outside – neither the server nor your browser.

🚧 Early development – not usable yet.

What's planned for later: [Roadmap](ROADMAP.md).
